# Receitário

Catálogo de receitas desenvolvido com React, Vite e TypeScript, consumindo a API pública [DummyJSON Recipes](https://dummyjson.com/recipes).`r`n`r`nRepositório: https://github.com/gcosta900/checkpointfrondend-5

## Deploy

URL pública na Vercel: **preencher após publicação**

## Funcionalidades

- Catálogo com as 50 receitas da API, busca por nome e filtro de culinária combinado.
- Favoritos temporários na página do catálogo.
- Detalhe por receita com ingredientes, modo de preparo e tempos.
- Tratamento para receita inexistente e rota 404 para páginas desconhecidas.

## Executar localmente

```bash
npm install
npm run dev
```

## Git Flow de entrega

Criar `main` e `develop`; desenvolver em pelo menos três branches `feature/*`, integrando cada uma à `develop` por Pull Request. Criar `release/1.0.0` a partir de `develop`, integrar à `main` por PR, marcar `v1.0.0` e publicar a Release no GitHub. Usar Conventional Commits.
